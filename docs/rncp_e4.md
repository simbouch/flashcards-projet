# RNCP E4 — Gestion de projet / Méthode (Agile)

## What to prove (goal)
- You managed the project with an **iterative approach** and tracked decisions.
- You can show a **backlog**, prioritization, and feedback loops.

## Evidence checklist (repo + external)

### Source control workflow
- [ ] Branching strategy + incremental commits.
  - Evidence: `dev` branch history (Git log), commit messages, PRs (if used)

### Backlog & planning artifacts (to add if missing)
- [ ] Backlog / user stories (recommended: add a simple markdown backlog in-repo).
  - Suggested file: `docs/project_backlog.md` (not yet present)
- [ ] Sprint/release planning notes (lightweight OK).
  - Suggested file: `docs/project_planning_notes.md`
- [ ] Risk register / decisions log (lightweight OK).
  - Suggested file: `docs/decisions_log.md`

### Feedback loop
- [ ] Evidence of iteration based on bugs/UX feedback.
  - Evidence: commits that fix reported issues (timeouts, UI flashcards loading, etc.)

## Report scaffold (copy/paste headings)
1. **Context & objectives**
2. **Method used**
   - Agile/iterative approach; cadence; how you prioritize.
3. **Backlog structure**
   - Epics/features, acceptance criteria.
4. **Tracking & reporting**
   - How you track progress (GitHub Projects / Trello / Markdown backlog).
5. **Retrospective**
   - What worked, what didn’t, what you’d improve.
